# KVRouterKit 2.0.0

KVRouterKit 2.0.0 is a major release that renames the module and adds a
high-performance navigation transition system for iOS 16 and later.

## Highlights

- Native SwiftUI hero zoom on iOS 18+, with the same call site falling back to
  a custom live-view hero transition on iOS 16 and 17.
- Built-in Slide, Fade, Scale, Scale and Fade, Shared Axis, Depth, Reveal and
  3D Flip push/pop styles.
- Automatic reverse animation for router pop, system back/dismiss and
  interactive leading-edge swipe pop.
- A compositor-friendly custom transition DSL using live navigation views and
  `UIViewPropertyAnimator` instead of full-screen transition snapshots.
- Preserved destination hierarchy and local SwiftUI state after returning to a
  previous screen.

## System and Native Animation Fix

Newer SwiftUI runtimes can reconcile a programmatic `NavigationStack` path by
calling the underlying `UINavigationController` with `animated: false`.
KVRouterKit 2.0.0 adds a controller-scoped compatibility policy that restores
the animated transaction only for matching, managed single push/pop operations.

Apple still owns `.system` and native iOS 18+ `.zoom` animation. KVRouterKit
does not install a custom animator for those backends. Unattached navigation
controllers, initial root installation, replacement, restoration and bulk stack
mutations remain unchanged.

## Migration From 1.x

Update the package dependency to 2.0.0 and select the `KVRouterKit` product:

```swift
dependencies: [
    .package(
        url: "https://github.com/khanhVu-ops/KVRouter.git",
        from: "2.0.0"
    )
]
```

Replace the old module import:

```swift
import KVRouterKit
```

Public router symbols remain unchanged, so most application code requires only
the dependency, product and import rename.

## Compatibility

- iOS 16.0+
- Swift 6 language mode
- Swift tools 6.2 / Xcode 26+
- Native hero zoom on iOS 18+
- Custom hero fallback on iOS 16 and 17
